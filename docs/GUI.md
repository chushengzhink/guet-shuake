# GUI 使用说明（面向使用者）

## 首次启动

双击 `GuetShuake.exe`（或开始菜单里的「GUET 畅课助手」），会出现一个独立窗口（用系统 Edge 的 app 模式渲染，没有地址栏，看起来像原生程序）。

- 配置、账号、登录状态、刷课进度都存在 `%LOCALAPPDATA%\GuetShuake`
- 日志在 `%LOCALAPPDATA%\GuetShuake\logs\gui.log`
- 想换数据目录：`GuetShuake.exe --data-dir D:\MyData`

## 三步

1. **添加账号**：左下输入框填个标识（如 `acc01`）→ 点「添加」
2. **登录**：点账号卡片右侧「登录」→ 弹出浏览器 → 微信扫码或 CAS 学号密码 → 登进课程首页后自动关闭
3. **刷新课程**：点「刷新课程」→ 勾选要刷的课 → 选节奏 → 「开始刷课」

运行中能看到每个账号的进度条和实时日志；「停止」是软停止，已完成的进度会保留。

## 节奏怎么选

| 节奏 | 段长 | 何时用 |
|---|---|---|
| `probe` | 125s | 想尽快刷完（推荐） |
| `normal` | 120s | 默认，稳一点 |
| `human` | 30s | 请求密度低，最保守 |
| `realtime` | 120s | 想按真实时间推进；可点「实测推荐」算并行路数 |
| `tick` | 120s | 单线程定时，配合 `run.py schedule` 挂计划任务 |

平台只校验「单段 ≤ 125 秒」，不校验真实时间，所以 `probe` 和 `realtime` 刷出来的进度完全一样，只是耗时不同。

## 常见问题

**点「登录」没反应**
精简版依赖系统 Edge。装个 Edge，或换完整版（内置内核）。

**提示「会话不可用」**
登录态过期（24 小时），点「重登」。

**某个活动一直不满**
换 `human` 再试；还不行看 `logs/gui.log` 里的响应码。

**杀毒软件报警**
PyInstaller 无签名程序的常见误报。源码全在仓库里，可以自己构建。

**能刷作业/考试吗**
不能，也不打算做。工具只处理视频和资料；作业与考试需要真实提交内容。
